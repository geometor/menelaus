src.geometor.menelaus.render¶

Publication-grade .euclid-graphic SVG renderer for 2D planar and 3D spherical Menelaus models.

Supports both:

  1. 2D Planar Model constructions (render_planar_svg(), export_planar_svg()), clipping infinite algebraic lines cleanly to a padded frame, rendering 3-vertex midpoint <path> segments, and avoiding point-label collisions.

  2. 3D Unit-Sphere \(S^2\) constructions (render_spherical_svg(), export_spherical_svg()), projecting exact SphericalPoint and GreatCircle elements orthographically onto 2D while preserving full interactive svg.euclid-graphic data-ref wiring for publish.
